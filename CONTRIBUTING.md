# Contributing

Thanks for wanting to contribute! We welcome contributions from anyone. To make collaboration smooth, please follow these guidelines.

## How to contribute

1. Fork the repository and create a branch for your change:
   - git checkout -b feature/your-feature
2. Make your changes on your branch, commit with clear messages, and push to your fork.
3. Open a Pull Request (PR) against this repository's default branch. Describe what you changed and why.

## Reporting issues

- Use the Issues tab to report bugs or request features. Provide steps to reproduce, expected vs actual behavior, and relevant logs or screenshots.

## PR guidelines

- One logical change per PR.
- Include tests or steps to reproduce if applicable.
- Keep changes small and focused.
- Use clear, descriptive PR titles and descriptions.

## Code style

- Follow existing style in the repository.
- Write clear, readable code and add comments where helpful.

## CI and checks

- Fix any failing checks before requesting review.

## Maintainers

- Maintainers will review PRs and may request changes. If you grant "Allow edits from maintainers", maintainers may push small fixes to your branch.
